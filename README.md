## 为什么公开这些

- **危机识别工具**（词库、分级）公开，是为了让家长、教师、关心的人也能用同一套语言识别信号；
- **治理规则**（SOP、督导、入驻细则）公开，是为了让每个参与者知道自己被什么规则约束；
- **话术与暗语**公开，是因为回避不会让风险消失，只会让需要帮助的人更孤立。
